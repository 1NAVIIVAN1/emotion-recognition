# Распознавание эмоций на основе ИИ-анализа медиапотока

Веб-приложение для определения эмоций на фото, видео и в реальном времени с веб-камеры с помощью двух моделей ИИ: **DeepFace (CNN)** и **Vision Transformer (ViT)**.

## Возможности

- 📷 **Анализ фото** — определение эмоций для всех лиц в кадре
- 🎬 **Анализ видео** — несколько видеофайлов одновременно, график эмоций по времени
- 📹 **Веб-камера в реальном времени** — анализ эмоций онлайн с камеры устройства
- 📄 **PDF-отчёты** — автоматическая генерация отчёта с графиком эмоций и ключевыми кадрами
- 🔄 Переключение между двумя моделями ИИ для сравнения результатов
- 🎨 Наложение рамок и подписей эмоций прямо на изображение и видео
- 🌍 Русский интерфейс и русские названия эмоций

## Что нового в 3-й итерации

- Обработка нескольких видеопотоков за один запуск
- Анализ эмоций в реальном времени через веб-камеру (WebRTC)
- Генерация PDF-отчётов: шапка, график эмоций по времени, ключевые кадры
- Обновлённый интерфейс: карточки результатов, метрики, фирменное оформление

## Технологии

- **Python 3.11**
- **Streamlit** — веб-интерфейс
- **DeepFace** — базовая модель на основе CNN
- **HuggingFace Transformers + ViT** — улучшенная модель на основе трансформера
- **MediaPipe** — детекция лиц (BlazeFace)
- **OpenCV** — обработка видео
- **streamlit-webrtc** — потоковая обработка веб-камеры в реальном времени
- **fpdf2 + matplotlib** — генерация PDF-отчётов
- **FFmpeg** — перекодировка в H.264 для веб-совместимости

## Установка и запуск

### Требования

- Windows 10/11
- Python 3.11
- 3-5 ГБ свободного места на диске

### Пошаговая установка

1. Клонировать репозиторий или скачать ZIP-архив.

2. Открыть командную строку в папке проекта и создать виртуальное окружение:

```
python -m venv venv
venv\Scripts\activate
```

3. Установить зависимости:

```
pip install -r requirements.txt
```

4. Запустить приложение:

```
streamlit run app.py
```

5. Приложение откроется в браузере по адресу `http://localhost:8501`

## Как использовать

1. Выбрать модель анализа (DeepFace или ViT) сверху страницы
2. Перейти на нужную вкладку: **«Фото»**, **«Видео»** или **«Веб-камера»**
3. Для фото/видео — загрузить файл через кнопку «Browse files»
4. Для видео — выбрать частоту анализа и нажать «Обработать все видео»
5. Для веб-камеры — нажать START и разрешить доступ к камере
6. Скачать обработанное видео и PDF-отчёт

## Архитектура решения

Приложение работает по пайплайну:

1. **Загрузка медиа** — пользователь загружает фото/видео или включает камеру через интерфейс Streamlit
2. **Детекция лиц** — MediaPipe BlazeFace находит координаты всех лиц в кадре
3. **Классификация эмоций** — выбранная модель (DeepFace или ViT) определяет эмоцию на каждом лице
4. **Визуализация** — на кадре рисуются цветные рамки и подписи через PIL
5. **Сборка результата** — для видео кадры склеиваются в файл, ffmpeg перекодирует в H.264; для отчёта формируется PDF с графиком и ключевыми кадрами

### Выбор модели под задачу

- **DeepFace** (~0.4 сек/лицо на CPU) — используется для веб-камеры в реальном времени, где приоритет скорость
- **ViT** (~1 сек/лицо на CPU) — используется для офлайн-анализа фото и видео, где приоритет точность

Это осознанный компромисс: трансформер ViT на CPU не укладывается в бюджет времени на кадр для реального времени, поэтому для потоковой обработки применяется более лёгкая CNN.

## Ограничения

- Модели обучены на фронтальных изображениях лиц (датасет FER2013)
- На лицах в профиль или сильно под углом точность снижается
- ViT в реальном времени требует GPU; на CPU для веб-камеры используется DeepFace
- Время обработки видео зависит от числа лиц в кадре и длины видео

## Распознаваемые эмоции

7 базовых эмоций по классификации Экмана: радость, грусть, злость, страх, удивление, отвращение, нейтральное.
